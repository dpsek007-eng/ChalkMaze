# 테스터 모집 키트 — 분필 미로

**게시는 직접 하셔야 합니다.** 아래 글은 그대로 복사해 붙이면 됩니다.
`https://play.google.com/apps/testing/com.ijcompany.chalkmaze`와 `https://groups.google.com/g/chalkmaze-testers`만 실제 값으로 바꾸세요.

---

> **2026-09-02 기준 ①~④ 완료.** 비공개 테스트 트랙이 살아 있고 링크가 채워져 있다.
> 이제 ⑤ 게시만 하면 된다.

## 순서 — 이 순서가 아니면 막힙니다

```
① 게임 설정 완료          ← 이게 안 되면 비공개 테스트를 못 엽니다
② 구글 그룹스 만들기
③ 비공개 테스트 트랙 개설 + 그룹 연결 + AAB 업로드
④ 옵트인 링크 복사
⑤ 커뮤니티에 게시  ←  여기서 처음으로 사람이 필요합니다
⑥ 12명이 모인 날부터 14일
```

**14일 시계는 게시한 날이 아니라 12명이 모인 날부터 돕니다.**
그래서 ①~④를 하루라도 빨리 끝내는 것이 전부입니다.

# 📋 게시글 — 한국어

> **제목:** [상호테스트] 분필 미로 — 클로즈드 테스트 12명 구합니다 (저도 해드립니다)

```
개인 개발자입니다. 클로즈드 테스트 요건(12명 × 14일) 때문에 테스터를 찾습니다.
여러분 앱도 똑같이 설치하고 14일 유지하겠습니다.

■ 분필 미로 (Chalk Maze)

어둠 속 미로를 제한된 분필로 정복하는 기억력 게임입니다.
지나온 길은 다시 어두워지고, 남는 건 벽에 그은 분필 자국뿐입니다.

분필은 층마다 한두 자루뿐이고 21층부터는 아예 주지 않습니다.
그래서 "얼마나 잘 외우느냐"가 아니라 "어디에 분필을 쓸 것인가"의 게임입니다.

  · 전 1000층, 층마다 규칙이 바뀝니다 (암흑 / 잠긴 문 / 역행 / 지워지는 분필 …)
  · 오늘의 미로 — 전 세계가 같은 미로를 풉니다. 결과를 이미지로 공유할 수 있습니다
  · 무료 / 오프라인 / 광고 있음(강제 시청 없음) / 57MB / Android 8.0 이상

■ 참여
   1) 그룹 가입: https://groups.google.com/g/chalkmaze-testers
   2) 옵트인: https://play.google.com/apps/testing/com.ijcompany.chalkmaze
   3) Play 스토어에서 설치

■ 부탁
   14일간 계정을 유지해 주시고 가끔 열어봐 주세요.
   (구글이 실제 사용 여부를 확인합니다)

■ 상호 테스트
   댓글에 앱 링크 남겨주시면 제가 먼저 설치하고 인증하겠습니다.

감사합니다.
```

# 📋 게시글 — 영어

> **Title:** [Testers Exchange] Chalk Maze — need 12 closed testers, I'll test yours first

```
Solo dev here, looking for closed testers (12 for 14 days).
Happy to install yours and keep it the full 14 days — I'll go first.

■ Chalk Maze

A memory maze played in the dark. Corridors go dark again once you leave them.
All that remains are the chalk marks you drew on the walls.

You only get one or two pieces of chalk per floor, and none at all past floor 21.
So it isn't "how well can you memorise" — it's "where do you spend your chalk".

  · 1000 floors, rules change as you descend
    (blackout / locked door / reversed / fading chalk …)
  · Daily Maze — everyone worldwide solves the same maze. Share your result as an image
  · Free / offline / contains ads (never forced) / 57MB / Android 8.0+

■ How to join
   1) Join the group: https://groups.google.com/g/chalkmaze-testers
   2) Opt in: https://play.google.com/apps/testing/com.ijcompany.chalkmaze
   3) Install from Play Store

■ Ask
   Please stay opted in for 14 days and open it now and then
   (Google verifies actual usage).

■ Reciprocal
   Drop your app link in the comments — I'll install it right away and prove it.

Thanks!
```
