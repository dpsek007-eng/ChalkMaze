# 테스터 12명 모집 키트 — 분필 미로

**게시는 직접 하셔야 합니다.** 아래 글은 그대로 복사해서 붙이면 됩니다.
`옵트인_링크` 부분만 Play Console 에서 받은 값으로 바꾸세요.

---

## 0단계 — 먼저 확인 (2주가 걸려 있습니다)

**Play Console → 테스트 및 출시 → 프로덕션** 에서 "프로덕션 액세스" 상태 확인.
이미 열려 있으면 **이 문서 전체가 필요 없습니다.** 요건은 앱이 아니라 계정 단위입니다.

---

## 1단계 — Google 그룹스 만들기 (이메일 12개 관리보다 훨씬 편함)

1. https://groups.google.com → **그룹 만들기**
2. 그룹 이름: `분필미로 테스터`
3. 그룹 이메일: `chalkmaze-testers` (원하는 이름)
4. **액세스 설정**
   - 그룹에 가입할 수 있는 사용자: **웹의 모든 사용자**
   - 게시물을 볼 수 있는 사용자: 그룹 회원
5. 만들기

이렇게 하면 **테스터가 스스로 가입**합니다. 이메일을 하나하나 받아 입력할 필요가 없습니다.

## 2단계 — 비공개 테스트 트랙에 그룹 연결

**Play Console → 테스트 → 비공개 테스트 → 테스터 탭**
→ 이메일 목록 대신 **Google 그룹스 주소** 입력 (`chalkmaze-testers@googlegroups.com`)
→ 저장 → **옵트인 링크 복사**

# 📋 게시글 — 영어판

> **Title:** [Testers Exchange] Chalk Maze — need 12 closed testers, I'll test yours too

```
Solo developer here, looking for closed testers to meet Google Play's
12 testers / 14 days requirement. Happy to install and test your app in return.

■ App: Chalk Maze
   A memory maze game played in the dark. Corridors go dark again once you
   leave them — all that remains are the chalk marks you drew on the walls.
   You only get a few pieces of chalk per floor, so the real question isn't
   "how well can you memorise" but "where do you spend your chalk".

   · Free / plays offline
   · Contains ads (never forced)
   · 51MB, Android 8.0+
   · 1000 floors

■ How to join
   1) Join the group: https://groups.google.com/g/chalkmaze-testers
   2) Opt-in link: 옵트인_링크
   3) Install from Play Store

■ Ask
   Please stay opted in for 14 days and open it now and then
   (Google verifies actual usage).

■ Reciprocal
   Drop your app link in the comments and I'll install it right away
   and keep it for 14 days. Happy to go first.

Thanks!
```
