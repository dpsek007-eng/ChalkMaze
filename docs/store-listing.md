## 앱 이름 (30자 제한)

```
분필 미로
```

**대안 (검색 노출 우선):**
```
분필 미로 : 어둠 속 미로 탈출
```

> 짧은 쪽이 브랜드로는 낫지만, Play 검색은 제목을 강하게 색인합니다.
> 첫 게임이라 인지도가 0이므로 **검색 노출을 택하는 편이 실리적**입니다.
> 다만 키워드를 과하게 욱여넣으면 구글이 제재하니 이 정도가 상한선입니다.

## 자세한 설명 (4000자 제한)

```
어둠 속에서 당신이 가진 것은 꺼져가는 횃불 하나와, 분필 몇 자루뿐입니다.

지나온 길은 다시 어두워집니다.
이 미로는 지도를 그려주지 않습니다.
남는 것은 당신이 벽에 남긴 분필 자국과, 밝혀 둔 화톳불뿐입니다.


■ 다 기억할 수는 없습니다

분필은 층마다 몇 자루뿐입니다.
모든 갈림길에 표시를 남길 수는 없습니다.

그래서 이 게임의 진짜 질문은 "얼마나 잘 외우느냐"가 아니라
"어디를 외우고, 어디에 분필을 쓸 것인가" 입니다.

찍어 둔 자국은 다시 밟으면 회수해서 다른 곳으로 옮길 수 있습니다.


■ 횃불이 꺼져도 잃는 것은 걸음뿐

횃불은 정해진 걸음 수만큼만 탑니다.
다 타면 마지막으로 밝힌 화톳불에서 다시 시작합니다.

분필 자국은 그대로 남습니다.
화톳불도 그대로 타고 있습니다.
그래서 실패한 회차도 헛되지 않습니다.

밝혀 둔 화톳불은 어둠 너머에서도 보입니다.
길을 잃었을 때 저 멀리 흔들리는 불빛 하나가, 이 게임에서 가장 반가운 순간입니다.


■ 1000층까지 내려갑니다

  채석장 (1~20층) — 규칙을 익힙니다
  수몰층 (21~99층)
  뼈의 회랑 (100~299층)
  재의 심도 (300~599층)
  무광층 (600~999층)
  최심부 (1000층)
  심연 (그 아래로, 끝없이)

깊어질수록 미로만 넓어지는 것이 아닙니다.
층마다 규칙이 바뀝니다.

  잠긴 문 — 열쇠를 찾아 되돌아와야 합니다
  역행 — 가장 깊은 곳에서 시작해 입구로 나갑니다
  짧은 횃불 — 평소의 3분의 2도 못 갑니다
  외딴 화톳불 — 이 층의 화톳불은 하나뿐입니다
  지워지는 분필 — 자국이 40걸음 뒤 사라집니다
  암흑 — 바로 옆 칸밖에 보이지 않습니다
  분필 없음 — 오직 머리로만


■ 바닥에 떨어진 것들

  기름병 — 횃불을 절반 되살립니다
  랜턴 — 잠시 더 멀리 보입니다
  삽 — 벽을 뚫어 지름길을 냅니다. 어디를 뚫었는지는 기억해야 합니다
  판자 — 구덩이를 건넙니다. 다음 회차에도 남습니다
  아리아드네의 실 — 매듭을 묶어두고 언제든 그 자리로 돌아옵니다
  나침반 — 잠시 출구 방향이 보입니다


■ 이런 분께

  · 한 손으로, 짧게 끊어서 하는 게임을 찾는 분
  · 운이 아니라 판단으로 풀리는 게임을 좋아하는 분
  · 미로, 미궁, 던전 탐험, 기억력 훈련에 끌리는 분
  · 화려한 연출보다 조용한 긴장을 좋아하는 분

인터넷 연결이 없어도 플레이할 수 있습니다.


IJ컴퍼니
```

## 데이터 안전 (Data Safety) 양식 답안

Play Console 이 묻는 순서대로 답하시면 됩니다.

| 질문 | 답 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유합니까? | **예** (AdMob 때문) |
| 전송 중 데이터가 암호화됩니까? | **예** |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | **예** (앱 삭제 시 기기 데이터 삭제, 광고 ID 재설정 가능) |

**수집 항목 — 아래 두 개만 체크:**

| 분류 | 항목 | 수집 | 공유 | 목적 |
|---|---|---|---|---|
| 기기 또는 기타 ID | 기기 또는 기타 ID | ✅ | ✅ | 광고 또는 마케팅 |
| 앱 정보 및 실적 | 진단 | ✅ | ✅ | 분석 |

> 이름·이메일·위치·연락처·사진·파일은 **전부 체크하지 않습니다.** 실제로 수집하지 않습니다.
> 게임 진행 데이터는 기기에만 저장되고 전송되지 않으므로 "수집"에 해당하지 않습니다.
